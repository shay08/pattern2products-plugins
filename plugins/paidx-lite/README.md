# PaidX Lite

PaidX Lite helps builders recognize possible paid work in public help requests, diagnose carefully, and draft respectful public replies and private follow-ups.

It includes the opportunity check, verified-versus-assumption distinction, community-rules reminder, and basic offer safeguards. It does not include PaidX’s full offer templates, detailed payment workflow, or upsell guidance.

## Install in Claude Code

```
/plugin marketplace add shay08/pattern2products-plugins
/plugin install paidx-lite@pattern2products
```
