# 3A+R Method

A practical way to sort through a suggestion, tool, feature, or idea without assuming every new thing needs to be added.

## The four choices

- **Adapt**: Change it so it fits your purpose, people, resources, or constraints.
- **Adopt**: Use it as it is because it fits the need.
- **Already Ahead**: Recognize that you already have a working approach or capability that meets the need. Keep moving without adding a duplicate.
- **Reject**: Set it aside because it does not fit, solve the right problem, or justify its cost.

The method helps make the reasoning visible. It does not make the decision for you.
