# Privacy Policy: PPCD Method Plugin

Last updated: October 24, 2026

The PPCD Method plugin by Sharon L. Simmons (SYGNL Technologies) is a set of written instructions that guide Claude to explain tasks one step at a time.

**What it collects:** Nothing. The plugin contains no code, no tracking, no analytics and no connections to outside servers. It does not collect, store, or send any personal information.

**Your conversations:** Your chats with Claude are handled by Anthropic under Anthropic's own privacy policy. The plugin author never receives or sees them.

**Questions:** sharon@sygnltech.com
