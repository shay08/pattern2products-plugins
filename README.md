# Pattern2Products Plugins

Plugins by **Sharon L. Simmons**, founder of SYGNL Technologies.

## PPCD Method

PPCD is a working method for building, learning and teaching. Every step answers four questions:

1. **Purpose**: What am I trying to accomplish?
2. **Place**: Where does it happen?
3. **Click**: What action do I take?
4. **Verified Done**: What can I see that proves it worked?

With this plugin, Claude guides you one step at a time and waits for you to say "done" before moving on.

## Install in Claude Code

```
/plugin marketplace add OWNER/pattern2products-plugins
/plugin install ppcd-method@pattern2products
```

## Use in the Claude app (no Claude Code)

Download `ppcd-method.zip` from this repo and upload it under your Claude skills settings.
